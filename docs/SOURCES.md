# Sources

The domain skills synthesize these books. Playbooks credit each method with a short author tag
(`[Dunford]`, `[Voss]`). `[Ries]` is Eric Ries; Al & Laura Ries are `[Ries & Ries]`. `[Dixon]` covers both
Matthew Dixon books, *The Challenger Sale* and *The JOLT Effect*; the framework name in the text says which. No book text is reproduced in this repo. Read the originals; they reward it.
