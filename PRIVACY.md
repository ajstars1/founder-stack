# Privacy policy

*Last updated: 2026-10-19*

founder-stack is a set of Markdown skill files for Claude Code. It has no servers, no MCP servers,
no hooks, no analytics, and no code that runs when you install it. The maintainers receive no data
from you.

## What the skills store, and where
When you use the skills, Claude writes these files **on your own machine**:
- `discovery/LEDGER.md`, `discovery/00-CONTEXT.md`, and debriefs in `discovery/interviews/` and
  `discovery/experiments/`, all inside your project. Interview and deal debriefs can contain the
  names of people you talked to, and any other details you choose to record.
- `~/.founder-stack/progress.md`, your `/learn` progress.

You control these files. Delete them at any time to remove the data.

## What is sent elsewhere
Nothing is sent by the plugin. When a skill needs current public facts (competitors, prices,
trademark or domain availability), it asks Claude to use Claude's own built-in web search. That is
governed by Anthropic's terms and privacy policy, not by this plugin.

## Retention
The maintainers retain nothing, because the plugin sends us nothing.
